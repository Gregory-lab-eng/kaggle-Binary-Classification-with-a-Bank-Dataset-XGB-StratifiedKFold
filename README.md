# 🧠 Kaggle competition - Binary Classification with Bank Marketing Data using XGBoost + StratifiedKFold

This repository showcases a full machine learning pipeline for binary classification using a bank marketing dataset. The goal is to predict whether a client will subscribe to a term deposit. The project evolves through 23 versions, each refining model performance, feature engineering, and evaluation strategy.

## 📌 Highlights 

- ✅ Initial setup with basic preprocessing and logistic regression
- 🔄 Switched to XGBoost for better performance and flexibility
- 📊 Introduced StratifiedKFold to handle class imbalance
- 🧪 Iterative tuning of hyperparameters (learning rate, max depth, n_estimators)
- 📈 Added ROC-AUC, precision-recall curves, and confusion matrix visualizations
- 🧮 Feature importance analysis using SHAP and XGBoost’s built-in methods
- 🧼 Cleaned categorical encodings and optimized memory usage
- 📦 Final version includes robust evaluation and export-ready predictions
